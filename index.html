--- # ============================================================================ # 本文件是什么？ # ---------------------------------------------------------------------------- # 这是网站的「首页」的入口文件，也就 4 行内容，非常简单。 # # 它的作用只有一件事：告诉网站生成程序（Jekyll）—— # 「网站根目录这一页，请套用 home 这个模板来显示」。 # # 真正的首页长什么样（顶部统计条、一排排文章卡片、翻页按钮）， # 全部写在 _layouts/home.html 这个文件里。 # 所以想改首页的外观，要改的是 _layouts/home.html，不是这个文件。 # # 运行流程： # 访客打开网站首页 → Jekyll 找到这个 index.html → # 看到 layout: home → 去 _layouts/home.html 里取出排版规则 → # 再把真实数据（文章列表、浏览量等）填进去 → 生成访客看到的网页。 # ============================================================================ layout: home # 上一行的意思：本页面使用名为 home 的布局模板 # （对应文件 _layouts/home.html）。 # 【可DIY修改】注意——一般不要改这一行，改了首页就会变成别的样式（比如变成一篇文章的样子）。 # 想调整首页内容，请去改 _layouts/home.html。 # Index page # 上面这行是原作者留的普通注释，不影响程序运行。 ---
