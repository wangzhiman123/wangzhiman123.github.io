{%- comment -%} ============================================================================ 本文件是什么？ ---------------------------------------------------------------------------- 这是「友情链接 · 读者自助申请区」，显示在友情链接列表下方。 · 两种模式，在 _data/links.yml 的 apply.mode 里随时切换： form —— 表单模式：读者按模板填字段 → 点提交 → 自动唤起邮件客户端， 申请内容已按固定格式排好，直接发到站长邮箱。 comment —— 评论模式：不提供表单，引导读者在本页评论区留言， 页面给出「一键复制」的留言模板，读者粘贴后修改即可。 none —— 完全关闭申请区。 · 为什么用邮件而不是服务器存数据？ 本站是纯静态网站（Jekyll + GitHub Pages / Nginx）， 页面上跑的只是 HTML，没有后端程序可以接收表单 POST。 邮件是纯静态站做"读者投稿"最稳妥、也最不容易被垃圾提交滥用的方式。 站长收到邮件后，在 tools\友链管理.html 里审核并录入即可。 · 防垃圾的三个小设计（不引入任何验证码服务）： ① 蜜罐字段：藏一个机器人不会填的输入框，填了直接静默丢弃； ② 提交频率限制：60 秒内只能提交一次； ③ 提交间隔计时：读者填表时能看到"距上次提交"的提示。 ============================================================================ 【怎么配置】（_data/links.yml） ---------------------------------------------------------------------------- apply: enabled: true # 总开关 mode: form # form | comment | none email: a@b.com # 收件邮箱（表单模式点提交时用这个） intro: 一段引导文字 # 显示在区块顶部 note: 一段审核须知 # 显示在表单下方，小字灰色 comment_anchor: #artalk-comments # 评论模式的"去评论区"按钮跳转锚点 ============================================================================ 【表单字段与校验规则】（前端 JS 校验，见文件末尾脚本） ---------------------------------------------------------------------------- 站点名称 * 2–30 字 必填 站点网址 * 必填，须以 http:// 或 https:// 开头，且域名含一点 站点简介 * 10–80 字 必填（审核友链主要看这条） 头像地址 选填，须是 http(s) 图片地址 联系方式 * 邮箱格式 必填，站长靠它回复你 补充说明 选填，≤200 字（可写备案号、交换条件等） ============================================================================ {%- endcomment -%} {%- assign _cfg = site.data.links -%} {%- assign _ap = _cfg.apply | default: empty -%} {%- assign _ap_enabled = _ap.enabled -%} {%- if _ap_enabled == nil or _ap_enabled == '' -%}{%- assign _ap_enabled = true -%}{%- endif -%} {%- assign _ap_mode = _ap.mode | default: 'form' -%} {%- assign _ap_email = _ap.email | default: _cfg.apply_email | default: site.social.email | default: '' -%} {%- if _ap_enabled and _ap_mode != 'none' and _ap_email != '' -%} {%- comment -%} 三重保护：① 总开关开了；② 模式不是 none；③ 收件邮箱不为空。 邮箱为空时静默不渲染申请区——否则读者点了提交也不知道发去哪，会更困惑。 {%- endcomment -%} {%- assign _intro = _ap.intro | default: _cfg.apply_text | default: '欢迎与本站交换友情链接。请按下方要求填写申请，审核通过后将展示在友链列表中。' -%} {%- assign _note = _ap.note | default: '本站仅收录内容健康、已备案、访问正常的站点；纯广告、采集站、跳转页一律不予通过。审核一般 1–3 天，结果会回复到您填写的邮箱。' -%}
