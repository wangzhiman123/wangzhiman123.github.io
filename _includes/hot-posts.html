{%- comment -%} ============================================================================ 本文件是什么？ ---------------------------------------------------------------------------- 这是「热门文章」小面板——显示在首页/文章页的右侧侧边栏， 位置在「最近更新」「热门标签」这些板块的下方。 它会把全站浏览量最高的几篇文章挑出来，列成一串，方便访客发现好内容。 · 数据源：_data/views.json —— 与文章卡片、文章页共用同一份浏览量数据， 因此三处显示的数值永远一致（构建时静态渲染，前端零请求、不会转圈）。 · 排序：按浏览量从高到低，取前 N 篇（默认 5，可用 include.max 覆盖）。 · 每项：文章标题（可点击，跳转文章页）+ 浏览量 + 发布日期。 · 样式：沿用主题 panel 板块的 section / panel-heading / list-unstyled 结构， 与「热门标签」「更新列表」视觉一致。 实现要点：Liquid 无法直接按外部哈希值排序，这里以「(常数 − 浏览量)::文章下标」 作为排序键——键等宽（7~8 位数字），字符串升序即浏览量降序。 ============================================================================ {%- endcomment -%} {%- comment -%} ---------------------- 第一步：读取两个基本参数 ---------------------- {%- endcomment -%} {%- assign MAX_HOT = include.max | default: 5 -%} {%- comment -%} 决定最多显示几篇文章。 include.max 的意思是"调用这个面板时传进来的 max 参数"（比如 {% include hot-posts.html max=8 %}）。 如果调用方没传，就用默认值 5。 【可DIY修改】把 5 改成 8，侧边栏就显示浏览量前 8 名的文章； 也可以在调用处传参（见 _layouts/home.html 的 panel_includes），那样不用改这个文件。 {%- endcomment -%} {%- assign _panel_title = site.data.locales[include.lang].panel.hot_posts | default: '热门文章' -%} {%- comment -%} 面板的标题文字。 先去语言包里找"热门文章"对应各语言的翻译；万一没找到，就直接用中文「热门文章」兜底， 保证任何时候都不会出现空白标题。 【可DIY修改】想改成「最受欢迎」「大家在看」等说法， 可以直接把最后的 '热门文章' 改掉（但改了以后英文站也会显示中文，合理方式还是改语言包）。 {%- endcomment -%} {%- comment -%} ---------- 第二步：给每篇文章造一个"排序用的暗号"（核心技巧） ---------- {%- endcomment -%} {%- comment -%} 为什么要这么绕？因为 Liquid（模板语言）没法直接对"浏览量"这种外部数据做排序。 所以这里换个思路：把浏览量换算成一个可以按字符串排序的编号—— 浏览量越高，编号越小；然后再按编号从小到大排，就等于是浏览量从高到低排。 {%- endcomment -%} {%- assign _keys = '' | split: '' -%} {%- comment -%} 先建一个空清单 _keys，用来装所有文章的排序暗号。 {%- endcomment -%} {%- for post in site.posts -%} {%- comment -%} 遍历全站每一篇文章 {%- endcomment -%} {%- if post.hidden != true -%} {%- comment -%} 跳过被标记为 hidden: true 的文章（这种文章不参与展示，也就不该出现在热门榜里）。 {%- endcomment -%} {%- assign _v = site.data.views[post.url] | default: 0 -%} {%- comment -%} 取出这篇文章的浏览量。 注意：数据来自 _data/views.json 里的记录；如果这篇文章还没有记录，就当作 0 次。 {%- endcomment -%} {%- assign _inv = 99999999 | minus: _v -%} {%- comment -%} 关键一步："反着算"。用 99999999 这样一个足够大的数减去浏览量， 得到"反序浏览量"：浏览越多，这个数越小。 例如 1000 次浏览 → 99998999；100 次浏览 → 99999899，前者更小、排更前。 {%- endcomment -%} {%- capture _item -%}{{ _inv }}::{{ forloop.index0 }}{%- endcapture -%} {%- comment -%} 把"反序浏览量"和"这篇文章在全站列表里的第几个（forloop.index0 从 0 开始数）" 用两个冒号拼在一起，做成一个暗号字符串，例如：99998999::3。 冒号后面的序号有两个用处： ① 万一两篇文章浏览量完全相同，还能按原有的先后顺序稳定排列，不会每次刷新顺序乱跳； ② 待会儿能靠这个序号把文章"找回来"。 {%- endcomment -%} {%- assign _keys = _keys | push: _item -%} {%- comment -%} 把造好的暗号放进 _keys 清单。 {%- endcomment -%} {%- endif -%} {%- endfor -%} {%- assign _keys = _keys | sort -%} {%- comment -%} 对清单做升序排序。 因为前面用了"反着算"的技巧，这里升序排完，实际上就是浏览量从高到低。 又因为所有暗号里的反序数都是 8 位数、长度一致， 所以按文字排序和按数字排序的结果完全相同，不会出现"999 比 1000 大"这种错乱。 {%- endcomment -%} {%- comment -%} ------------------- 第三步：把排好序的前几名画成列表 ------------------- {%- endcomment -%} {%- if _keys.size > 0 -%} {%- comment -%} 只有至少有一篇文章时才生成这个面板，否则整块不出现、不留空白。 {%- endcomment -%}
