{%- comment -%} ============================================================ 【本文件是什么？】 百度统计（Baidu Tongji）· 站点流量分析组件 v1 ------------------------------------------------------------ 作用：在页面中加载百度统计的 hm.js，把访客访问行为上报到百度统计后台， 用于在 https://tongji.baidu.com 查看全站流量报表 （浏览量 PV、访客数 UV、来源渠道、地域、设备、入口页等）。 一句话概括：这是"后台报表用的探头"，只负责默默记录有多少人来过， 访客在网页上完全看不到它的存在。 ！！它【不负责】页面上"浏览量数字"的显示 ！！ 页面上文章卡片 / 文章页 / 热门文章里显示的数字，来自 _data/views.json（构建时静态渲染），与百度统计是两条互不相干的链路。 百度统计没有"读取单篇文章浏览量"的前端接口，不能用来做前台显示。 开关：_config.yml → analytics.baidu.id · 填了（非空）→ Chirpy 主题会在 中自动加载本文件； · 留空 → 整段不输出，页面上不会出现任何百度统计代码。 加载机制见主题 _includes/head.html 里的： {% raw %}{% for analytics in site.analytics %} ... {% include analytics/{{ platform }}.html %} ... {% endfor %}{% endraw %} —— 所以只要 analytics.baidu.id 非空，本文件就会被自动引用， **不需要**再手动去 head / footer 里加 {%- endif -%}
