{%- comment -%} ============================================================================ 【本文件是什么？】 Giscus 评论组件（基于 GitHub Discussions）—— 对应_config.yml 的 comments.provider: giscus 官网与配置生成器：https://giscus.app/ 一句话概括：这段代码在页面底部"长出"一个评论区， 读者用 GitHub 账号登录即可留言，评论数据存在 GitHub Discussions 里。 【为什么自己写一份而不直接用主题自带的？】 为了和同目录下的 artalk.html 保持完全一致的设计约定（懒加载、 未启用不渲染、跟随主题明暗、超时兜底），并且能精确控制容器 id （友链页的"前往评论区"按钮要跳到它）。 ⚠️ 换评论系统时必须同步改两处，否则按钮会跳到页面顶部： ① 本文件的 $container.id ② _data/links.yml 的 apply.comment_anchor ============================================================================ ⚠️ 四个刻意做的设计 ---------------------------------------------------------------------------- 1. 【前置条件探测】Giscus 需要仓库开启 Discussions 并安装 giscus app。 配置项（repo/repo_id/category…）填了不代表能用，所以这里统一以 repo + repo_id + category_id 三项齐全为准，缺一项就不渲染， 避免读者看到一个空白的评论区。 2. 【懒加载】滚动到附近才下载 client.js（省首屏流量）。 另外给 iframe 加 loading="lazy"，让浏览器自己也别急着加载。 3. 【跟随主题明暗】Giscus 官方支持 postMessage 换主题， 这里监听 Chirpy 的深浅色切换消息并转发给 iframe， 不会出现"网站黑了、评论区还是白的"。 4. 【超时兜底 —— 重要】 Giscus 的评论界面在一个跨域 iframe 里，加载链路过长时表现为 "页面底部一片空白"，读者会以为评论坏了。所以设了超时计时器： 到点仍没就绪就显示友好提示 + 邮件入口，绝不留空白。 ============================================================================ 【配置方法】_config.yml ---------------------------------------------------------------------------- comments: provider: giscus giscus: repo:用户名/仓库名 # 必填，需是公开仓库 repo_id: R_kgDOxxxxxxx # 必填 category: Announcements # 必填，讨论区类别名 category_id: DIC_kwDOxxxxxxx # 必填 mapping: pathname # 页面与讨论的映射方式 strict: 0 # 0=模糊匹配 1=严格匹配 input_position: bottom # 输入框位置 top / bottom lang: zh-CN # 界面语言 reactions_enabled: 1 # 是否显示表情反应 【这些值去哪拿？】打开 https://giscus.app/ ，按提示一步步填， 页面底部会直接生成对应的配置代码，复制粘贴即可。 repo_id 和 category_id 必须从那里拿，手写编不出来。 ⚠️ 内联脚本禁用 `//` 行注释：_config.yml 开启了 compress_html， 正式构建会压掉全部换行，`//` 会把后续代码一并注释掉。 一律用 `/* */`，语句以 `;` 结尾，分支加花括号。 ============================================================================ {%- endcomment -%} {%- assign _g_repo = site.comments.giscus.repo | default: '' | strip -%} {%- assign _g_repo_id = site.comments.giscus.repo_id | default: '' | strip -%} {%- assign _g_cat = site.comments.giscus.category | default: '' | strip -%} {%- assign _g_cat_id = site.comments.giscus.category_id | default: '' | strip -%} {%- if _g_repo != '' and _g_repo_id != '' and _g_cat_id != '' -%} {%- comment -%} 只有"仓库 + 仓库ID + 分类ID"都填了才输出。 缺任何一项说明 giscus 还没配好，这时页面上不出现评论区 （友链申请区会同步降级成「改为邮件提交」，不留死按钮）。 {%- endcomment -%} {%- assign _g_mapping = site.comments.giscus.mapping | default: 'pathname' -%} {%- assign _g_strict = site.comments.giscus.strict | default: 0 -%} {%- assign _g_input = site.comments.giscus.input_position | default: 'bottom' -%} {%- assign _g_lang = site.comments.giscus.lang | default: 'zh-CN' -%} {%- assign _g_react = site.comments.giscus.reactions_enabled | default: 1 -%} {%- comment -%} 可选：把Giscus 脚本换成本地/国内镜像。留空用官方地址。 {%- endcomment -%} {%- assign _g_src = site.comments.giscus.src | default: 'https://giscus.app/client.js' | strip -%} {%- comment -%} 超时兜底时长（毫秒）。 {%- endcomment -%} {%- assign _g_timeout = site.comments.giscus.timeout | default: 15000 -%} {%- comment -%} 加载中 / 降级提示的样式（很轻，不影响首屏）{%- endcomment -%} {%- endif -%}
