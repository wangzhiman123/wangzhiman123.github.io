{%- comment -%} ============================================================ 【本文件是什么？】 阅读量统计 · 不蒜子官方版（前端实时显示） ------------------------------------------------------------ 用途：当 _config.yml 里 viewcount.provider = busuanzi 时， 由本文件负责把「这篇文章被看了多少次」这个数字实时显示出来。 与另一方案的区别（static 静态渲染版）： · static 版：数字由构建时从 _data/views.json 印死在网页里， 打开即可见、不转圈、不发请求，但数字有延迟（要等定时任务刷新）。 · 本文件（busuanzi 版）：页面里只放一个"空标签"，由不蒜子官方 mini.js 在访客浏览器里实时去取数字并填进去。 优点是"数字实时"，缺点是打开后有约 1 秒空窗（显示"…"）， 网络不通时会一直空白。 【两个 id 约定，名字不能改】—— 这是不蒜子脚本内置的约定： busuanzi_container_page_pv —— 装数字的"外层容器"（控制显隐用） busuanzi_value_page_pv —— 真正放数字的那个空标签（脚本往这里填） 脚本就是靠这两个名字找到位置、把数字填进去的。 ！！铁律：本文件里绝对不能出现 // 行注释 ！！ ------------------------------------------------------------ 原因：_config.yml 开启了 compress_html，生产构建会把整份 HTML 的换行 全部压掉。一旦代码里出现 // 行注释，它会把「本行之后」的所有代码一路 注释到脚本结尾，导致功能失效。所以： ① 注释一律用 /* */ 块注释，禁用 // ② 每条语句都以 ; 结尾，不依赖 JavaScript 的自动分号补全 （这与 _includes/pageviews/goatcounter.html、_includes/busuanzi-site-pv.html 的约定完全一致。） 【脚本地址为什么用 // 开头】 {%- comment -%} 把文章页作者信息旁边那个 #pageviews 里的转圈图标替换掉。 原先 post.html 里放的是 ， 这里用 JS 把它清掉，换成一个"等待中的 …"， 然后把不蒜子的数字容器放进去（脚本会往 busuanzi_value_page_pv 里填数字）。 {%- endcomment -%} {%- endif -%}
