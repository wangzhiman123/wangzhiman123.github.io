{%- comment -%} ============================================================================ 本文件是什么？ ---------------------------------------------------------------------------- 这是「友情链接」板块的渲染组件。前台任何位置想显示友链，都用一行 {% include friend-links.html %} 调用它即可，不必重复写渲染代码。 · 数据源：_data/links.yml —— 全站唯一一份友链数据 · 渲染方式：构建时由 Liquid 静态生成 HTML，前端零请求、无闪烁 · 默认图标：logo 留空时，按站点名首字 + 固定调色板生成彩色首字方块 ============================================================================ 【怎么调用（可选参数）】 ---------------------------------------------------------------------------- {% include friend-links.html %} 使用 links.yml 里全部配置 {% include friend-links.html max=6 %} 最多显示 6 条 {% include friend-links.html layout="list" %} 强制列表式布局 {% include friend-links.html new_tab=false %} 强制在当前窗口打开 {% include friend-links.html show_apply=false %} 隐藏底部「申请友链」区块 {% include friend-links.html title="我的伙伴" %} 覆盖板块标题 {% include friend-links.html icon=false %} 不显示板块图标（用于侧边栏面板） 说明：所有参数都可省略，省略时一律回落到 _data/links.yml 顶层的站点级配置。 这样日常增删友链不用碰任何模板，只改 links.yml 一个文件。 ============================================================================ 【数据校验与兜底（重要）】 ---------------------------------------------------------------------------- 1. 整站开关：enabled: false 时本组件什么都不输出（不留空白）。 2. 缺 url 的条目直接跳过——没有地址的链接点了没意义。 3. 缺 name 的条目跳过——避免卡片上出现空白标题。 4. 缺 logo 的条目 → 自动生成"首字彩色方块"默认图标。 5. logo 是图片，图片 404 或加载失败时（onerror）→ JS 自动切换成默认图标， 不会出现碎图。这是"加载异常兜底显示"的核心。 6. 整份列表为空时 → 输出一行灰色提示"友链暂未开放"，而不是空白页面。
