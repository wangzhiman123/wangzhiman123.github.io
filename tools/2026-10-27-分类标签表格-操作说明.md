# 分类标签表格 · 操作说明

> 一句话：**表格是唯一的数据源头**。改表格 → 跑一次导入 → 文章自动跟着变。
> 不需要打开任何一篇文章去手动改 front matter。

---

## 一、三步走

| 步骤 | 双击这个（在 `tools` 文件夹里） | 对应命令 | 做什么 |
| --- | --- | --- | --- |
| ① 导出 | `1-导出分类标签表格.bat` | `python scripts/export_tags_table.py` | 把 51 篇文章当前的分类标签抓成一张表 |
| ② 修改 | — | — | 用 Excel / WPS 打开 `tools\文章分类标签表.csv` 改，保存 |
| ③ 导入 | `2-导入分类标签到文章.bat` | `python scripts/import_tags_table.py` | 按表里的内容回写每篇文章，改前自动备份 |

导入的 bat 会**先预演一遍**（只显示"哪篇从什么改成什么"，不动文件），你看过没问题再按 `Y` 才真正写入。多一层保险。

出报告（可选）：`python scripts/gen_tag_report.py` → 生成 `tools\文章分类标签整理报告.md`。

---

## 二、表格每一列怎么填

| 列名 | 能不能改 | 填写规则 |
| --- | --- | --- |
| 序号 | 随便 | 只用于查看，脚本不读 |
| **一级分类** | **可自由新增** | 随便填。想加「税务」「读书」这种新大类，直接在表里写就行，**不用改任何代码**，会自动生成对应的分类页 |
| **二级分类** | 可改 | 自由填写。填一个新名字就等于**新建一个分类页**，导入时会提示你 |
| **标签** | 可改 | 多个标签用顿号隔开，例如 `一审、原告方`。中文逗号、英文逗号、分号也都认。留空 = 这篇文章不要标签 |
| 文章标题 | 随便 | 只用于查看，脚本不读 |
| **文件名** | **千万不要改** | 脚本靠这一列找到对应文章。改错 = 找不到文件 = 该行被跳过 |
| 发布日期 | 随便 | 只用于查看，脚本不读 |

> **唯一的硬规则**：分类名和标签名里不能出现 `,` `:` `#` `[` `]` 这几个符号（中文的 `，` `：` 也不行）。
> 原因很实在——它们是 YAML 的语法符号，混进名字里会把 `categories: [工作, 诉讼实务]` 这行拆坏，
> 导致整篇文章的分类失效。真填了，导入时会明确告诉你哪一行的哪个名字有问题，改掉即可。

### 分类的填写示范

```

```

## 三、导入时看到的提示是什么意思

| 提示 | 含义 | 要处理吗 |
| --- | --- | --- |
| `✔ 文件名` + `旧 → 新` | 这篇会被改 | 看一眼对不对 |
| `= 文件名（内容其实没变）` | 表里填的和文章里现有的一样 | 不用管 |
| `没有需要修改的文章` | 表格和文章完全一致 | 正常，说明上次已经同步过 |
| `⚠ 找不到这个文件` | 「文件名」那列写错，或文章已改名 | 要改表 |
| `⚠ 二级分类是空的` | 漏填 | 补上 |
| `⚠ 标签有 7 个，太长了` | 一篇最多 6 个标签（建议 2~4 个） | 精简 |
| `⚠ ...里含有「,」，写进 YAML 会破坏分类结构` | 分类名或标签名里有 `,` `:` `#` `[` `]` | 把这几个符号去掉 |
| `ℹ 出现 N 个新的一级分类` | 你新增了大类，会生成新的分类页 | 正常，不用管，也不需要改代码 |
| `ℹ 出现新的二级分类` | 同上，只是层级不同 | 确认是你想要的即可 |

**出问题的行只是被跳过，不影响其他行照常导入**，所以可以一边改一边导。

## 四、安全网

1. **每次导入前自动备份**：`_backup\autosave-年月日-时分秒\`，里面只有这次被改动的文章。
   要还原：把里面的文件拷回 `_posts\` 即可。
2. **只动两行**：脚本只改 `categories:` 和 `tags:` 这两行，正文、标题、图片、日期一概不碰，
   连这两行后面的中文注释都原样保留。
3. **没变就不重写**：内容一致的文章不会被重写，文件修改时间不变，
   网站上不会莫名出现"更新于 xx"。
4. **可以反复跑**：跑一次和跑十次结果一样。
5. 当初整理前的**全量原始备份**在 `_backup\posts-20261027\`。

## 五、几个坑，提前说

- **别另存成 .xlsx**。脚本读的是 `.csv`；另存成 xlsx 就读不到了。要改就原地保存这个 csv。
- **Excel 保存时弹出的"是否保留此格式"选「是」**。选"是"才是 CSV。
  如果提示编码，选 **CSV UTF-8** 最稳；就算存成了 ANSI/GBK 脚本也能自动识别，不用慌。
- **不要改「文件名」列**，那是脚本唯一的索引。
- **表格里新增行不会被识别**（脚本只按已有文章回写）。新写的文章请先用
  `1-导出分类标签表格.bat` 重新导一次表，新文章就会出现在表里。
- 表格里**删掉某一行**不会删除文章，只是这篇不再被管理。
- **新加的一级分类，导出时会排在「工作 / 生活 / 学习」后面**（再按名称排序）。
  这只影响表格和报告的排列顺序，不影响网站。想让它排到前面，把
  `scripts\export_tags_table.py` 里 `LEVEL1_ORDER = ["工作", "生活", "学习"]`
  这行加上你的新分类即可（纯排版，可改可不改）。
