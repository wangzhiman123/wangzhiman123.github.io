# 稿件转 Markdown 使用说明（Word / HTML 通用）

> 一句话：**把 Word 稿子或网页 HTML 双击转成博客文章，再在浏览器里边改边看，满意了发布。**

---

## 一、这套工具有几个文件

都在 `tools` 文件夹里，互相配合用：

| 文件 | 干什么用 | 怎么打开 |
| --- | --- | --- |
| `5-Word或HTML转Markdown.bat` | 把 `.docx` / `.html` / `.htm` 转成 `.md` 文章，自动写好表头 | **双击** |
| `6-文章编辑器.html` | 左右分栏，左边改、右边实时看；也能直接粘贴 HTML 转换 | **双击**（用浏览器打开） |
| `word2md.ps1` | bat 背后真正干活的程序 | **不用管它**，也别删 |

> 原来那个 `5-Word转Markdown.bat` 改名成了 `5-Word或HTML转Markdown.bat`，
> 因为现在不光能转 Word，也能转网页。功能是叠加的，老的 `.docx` 用法完全没变。

**这套工具不需要安装任何东西。**
不用装 Python、不用装 pandoc、不用装 Word 插件、不用联网。
用的是 Windows 自带的 PowerShell 和浏览器，换台电脑、隔一年再用，照样能跑。

> **这三个文件要放在同一个文件夹里**（`bat` 和 `ps1` 必须同目录）。
> 放在博客的 `tools` 文件夹里，会直接写进 `_posts`；
> 复制到桌面、U盘、别人的电脑上，会自动改成「便携模式」，把文章放进同目录的 `输出` 文件夹 ——
> 不用配置、不用指定路径、不会报错。详见下面的「八、当成随身小工具用」。

## 二、第一步：把稿子转成文章

### 情况一：稿子是 Word（.docx）

**方式 A：双击 bat，然后把文件拖进黑窗口**

1. 打开 `tools` 文件夹，双击 `5-Word或HTML转Markdown.bat`
2. 屏幕上出现一个黑色窗口，提示「请把要转换的文件拖进本窗口」
3. 用鼠标把 `.docx` 文件**拖进这个黑窗口**，松手
4. 窗口里会出现一串文件路径（这是正常的），**按一下回车**
5. 先回答一个问题：**正文开头那行标题，删还是留？**
   - 输入 `1` 或直接回车 = **删掉**（推荐）。网页顶部已经显示标题了，正文再来一遍就重复了
   - 输入 `2` = **保留**，正文开头照样留着这条标题
   - 这个选择本次所有文件通用，只问一次
6. 接着按提示回答 4 个问题，每个问题**都可以直接按回车用默认值**：
   - 文章标题 —— 回车 = 自动用 Word 里认出来的标题
   - 分类编号 —— 回车 = 1 号（工作 / 诉讼实务）
   - 标签 —— 回车 = 先不填，之后在编辑器里补
   - 发布日期 —— 回车 = **昨天**（稿子一般隔天发；想发别的日子当场输入 `2026-10-30` 即可）
7. 看到「[完成] 文章已生成」，就转好了

**方式 B：直接把文件拖到 bat 图标上**

用鼠标按住 `.docx` 文件，拖到 `5-Word或HTML转Markdown.bat` 的图标上松手，
后面的问答步骤同上。拖一整个文件夹也行，里面所有的 `.docx` / `.html` 会一起转。

### 情况二：稿子是网页（.html / .htm）

有两种做法，看你要不要当场看效果。

**做法 A：拖进编辑器（推荐，能边转边看）**

1. 双击 `tools\6-文章编辑器.html`，用浏览器打开
2. 把 `.html` 文件**直接拖进浏览器窗口**，会弹出一个窗口
3. 里面能看到识别出来的标题，确认一下分类、标签；下面有个勾选项
   **「正文里保留那条标题」**，默认是**没勾**的（= 正文里不重复出现标题），
   想让正文开头也留一条标题就勾上
4. 点**「替换全文」**
5. 左边立刻出现转换好的 Markdown，右边是排版效果，接着改就行

**做法 B：拖进 bat（适合一次转好几篇）**

和 Word 完全一样：双击 bat → 把 `.html` 拖进黑窗口 → 回车 → 回答问题。

**手上的 HTML 只是一段代码，没有文件？**

双击编辑器 → 点顶部**「导入 HTML」**→ 把代码粘贴进大框里 → 填标题和分类 → **「替换全文」**。

这段代码可以是：
- 网页上「查看源代码」复制下来的整页源码
- 别人给你的富文本片段（只有 `<p>`、`<h2>` 这类标签）
- 公众号文章、旧网站文章导出的 HTML

### 转完之后，东西在哪

**在博客的 `tools` 里运行**（能直接发布）：

```
_posts\2026-10-28-post-051.md      ← 生成的文章
assets\img\post-051\image1.png     ← 只有 Word 里的图片才会导出来
```

**在别处运行**（便携模式，自动判断，不会问你）：

```
输出\2026-10-28-post-001.md              ← 生成的文章
输出\assets\img\post-001\image1.png      ← 要发博客时，把 post-001 这个文件夹
                                            丢进博客的 assets\img\ 里
```

- 文件名里的编号 `post-051` **会自动往后接**，你已经用到 `post-050` 了，所以下一篇是 `051`，不会撞车。
  便携模式从 `post-001` 开始，各文件夹各算各的。
- 网页里的图片是网络地址，不占你服务器空间，所以**不会**导出到 `assets`。

## 三、第二步：在编辑器里改，边改边看

### 打开方式

双击 `tools\6-文章编辑器.html`，会用浏览器打开（推荐 Edge 或 Chrome）。

### 怎么用

1. 点左上角**「打开文件」**，选中刚生成的那篇文章
   （或者直接把 `.md` 文件**拖进浏览器窗口**，一样的效果）
2. 左边是源码，右边是效果，**左边打一个字，右边马上变**
3. 中间那条分隔线可以左右拖动，调整两边宽度
4. **两边同步滚动**：左边往下滑，右边跟着滑到对应位置（反过来也一样）。
   不想要这个效果，点右上角**「⇅ 同步滚动」**按钮关掉，它会记住你的选择
5. **图片自动压缩**：打开文章时会自动给图床图片补压缩参数，
   随时也可以点顶部**「压缩图片」**再手动跑一次（重复点不会叠加参数）
6. 不想要这篇了？点顶部**「清空」**，左边内容连同浏览器里保存的草稿一起清掉
   （会先弹窗问你一次；已经下载到硬盘的 `.md` 文件不受影响）
7. 改满意了点**「下载 .md」**，文件名会自动按日期和标题起好
8. 把下载下来的文件**剪切粘贴回 `_posts` 文件夹**，覆盖原来那个

> **要直接复制代码？** 点顶部**「复制 Markdown」**，整篇代码（含文章表头）就进了剪贴板，
> 按钮会变成「✓ 已复制」，屏幕下方还会冒一句提示，粘到哪儿都行。
> 在「导入 HTML」的窗口里转完，也可以先点**「复制结果」**——只复制、不动左边的编辑器。

> **粘贴一大段会卡吗？** 不会。以前"卡死"有两个原因：一是浏览器把几十万字符塞进输入框本身就慢到几分钟，
> 二是预览每次都要整篇重画。现在超过 3 万字的粘贴会由工具自己接管（直接整段塞进去，几毫秒），
> 预览也改成切段、一屏一屏地画，右上角显示「正在渲染 xx%」，画的过程中照样能打字、能滚动。
> （代价：这种超大粘贴不能用 Ctrl+Z 撤销，粘错了点「清空」重来最快；小段粘贴不受影响，撤销照常。）

> **为什么要「下载」再粘贴回去？**
> 浏览器出于安全限制，不能直接改你硬盘上的文件，只能「另存一份」。
> 这是浏览器所有网页都有的限制，不是工具偷懒。
> 熟练之后，你也可以在左边改完点「复制 Markdown」，直接粘到记事本里保存。

编辑器顶部会显示一张**表头卡片**（标题 / 日期 / 分类 / 标签）。
如果标题或分类没认出来，卡片上会有黄字提醒，你直接在左边源码里改就行。

> **日期默认是「昨天」**：不论用 bat 转还是用编辑器导入 HTML，没特别指定时都会填**当前日期的前一天**，
> 想换别的日子，转的时候输入日期，或在「导入 HTML」窗口里点日期框选。

## 四、转换规则：原来的东西变成了什么

### Word 里是

| Word 里是 | 转出来是 | 效果 |
| --- | --- | --- |
| 标题 1 / 标题 2 / 标题 3 | `#` / `##` / `###` | 文章小标题，自动进右侧目录 |
| 加粗 / 斜体 | `**加粗**` / `*斜体*` | 加粗 / 倾斜 |
| 插入的超链接 | `[文字](网址)` | 能点的蓝色链接 |
| 手打的一串网址 | `<https://...>` | 自动变成能点的链接 |
| 手打的邮箱 | `<name@qq.com>` | 自动变成发邮件链接 |
| 表格 | Markdown 表格 | 带边框的表格 |
| 项目符号 / 自动编号 | `-` 和 `1.` | 圆点列表 / 数字列表 |
| 引用段落 | `>` | 左侧带竖线的引用块 |
| 嵌在文件里的图片 | 导出成文件 + `![]()` | 正常显示，且已压缩 |

### 网页 HTML 里是

| HTML 里是 | 转出来是 | 说明 |
| --- | --- | --- |
| `<h1>` ~ `<h6>` | `#` ~ `######` | 网页大标题会被认成文章标题，正文里不重复 |
| `<b>` / `<strong>` | `**加粗**` | |
| `<i>` / `<em>` | `*斜体*` | |
| `<a href="...">文字</a>` | `[文字](网址)` | 文字本身就是网址的，写成 `<网址>` |
| 网页上的**纯文本网址**（没包 `<a>`） | `<https://...>` | 网页里常把网址当普通文字排，转出来自动变成能点的链接；后面紧跟汉字、全角标点、句号的，只取网址本身 |
| `<img src="...">` | `![说明](网址)` | 图床图片自动补压缩后缀 |
| `<table>` / `<tr>` / `<td>` | Markdown 表格 | 第一行当表头，`colspan` 合并列自动补空 |
| `<ul>` / `<ol>` / `<li>` | `-` 和 `1.` | 嵌套列表自动缩进 |
| `<blockquote>` | `>` | 引用块 |
| `<pre>` / `<code>` | 三个反引号的代码块 | 带 `language-xxx` 的会标上语言 |
| `<br>` | 行尾两个空格 | 段内换行 |
| 导航、页脚、侧边栏、广告、脚本、样式 | 直接丢掉 | 不会混进正文 |
| `&nbsp;` `&amp;` 这类转义符 | 还原成正常字符 | |

**标题是自动认的**，不用你手动标：

- Word：用了「标题 1/2/3」样式就按层级转；整篇没用样式、只在第一段写了大标题，也会被认成文章标题。
- 网页：先看 `og:title`，再看网页标题（`<title>`），最后看正文第一个 `<h1>`。

认出来的标题会写进表头的 `title`。至于**正文里原来那行标题**：

- 默认从正文里**删掉**，因为页面顶部已经显示标题，正文再来一遍就重复了；
- 想让正文开头也保留一条标题，就选「保留」——bat 里回答 `2`，
  编辑器里勾上「正文里保留那条标题」，命令行加 `-KeepTitle`。

## 五、图片是怎么处理的

分两种情况，都是自动的，你不用管：

**① 图片是网络图片**（比如搜狐图床链接、网页里的图）

自动在网址后面补上压缩参数，让图床服务器当场缩图：

```
原来：https://q6.itc.cn/images01/xxx.jpeg
转后：https://q6.itc.cn/images01/xxx.jpeg?x-oss-process=image/resize,w_1000/format,webp
```

读者少下载九成流量，肉眼几乎看不出区别。
已经带参数的会更新宽度，**不会重复叠加成一长串**。

**这里要特别说明一句**：这个「压缩」不是重新存一张小图，而是**改网址**——
图床（搜狐的 itc.cn 底层是阿里云 OSS）认网址里的参数，读到 `resize,w_1000/format,webp`
就当场把图缩小并转成 WebP 再发给你。好处是原图不动、随时能改回去、磁盘上不占额外空间。

在编辑器里，这件事有两处会自动做：

- **导入 HTML 时**自动补（转换那一刻就补上）
- **打开 .md 时**也自动补一次，顺便把不完整的网址（下面那条）修好
- 任何时候想再跑一次，点顶部**「压缩图片」**即可，重复点不会叠加

只对 `itc.cn` 这类支持参数的图床有效。别的网站（比如 `example.com/a.png`）
参数加了也没用，工具会原样保留，并在底部提示「xxx 不支持压缩」。

**② 网址不完整导致图片显示不出来？已自动修**

老网页里的图片地址经常写成这两种残缺样子，浏览器在本地一打开就变成本机路径，
所以图是空的：

| 你手上的地址 | 问题 | 修好后 |
| --- | --- | --- |
| `//up.itc.cn/a.jpg` | 少了 `https:` | `https://up.itc.cn/a.jpg` |
| `/up.itc.cn/a.jpg` | 还少一个斜杠 | `https://up.itc.cn/a.jpg` |
| `/assets/img/a.jpg` | 这是博客自己的图，**不动** | 原样保留 |

转换（bat 和编辑器都算）会自动补全；编辑器预览时还会额外把 `/assets/...`
临时换算成 `../assets/...`，这样你本地也能看到自己博客里的图。
**这只是预览时的换算，左边源码一个字都不改**，发布出去还是原来的样子。

万一图片确实加载不出来（被删了、对方禁止外链、断网），预览区不会留一片空白，
而是显示一个虚线框，写着「图片加载不出来：完整网址」，点一下能用浏览器打开它，
方便你判断到底是地址写错还是图没了。

网页里那种「先放一张占位小图、滚动到了才加载真图」的懒加载图片
（真地址藏在 `data-src` 里的），也能认出真正的图片地址。

**② 图片是插在 Word 文件里的**

导出到 `assets\img\文章编号\` 时顺手压缩：

- 宽度超过 1000 像素 → 等比缩小
- 高度超过 3000 像素（超长截图）→ 也等比缩小
- JPEG 按 85% 质量重新保存
- 通常能瘦掉 60%~90%，截图里的字照样看得清

压缩万一失败（极少数精简版系统缺组件），会自动改成**原样复制**，
绝不会因为压缩不了就中断整个转换。

## 六、常见问题

**Q：转出来的文章里有一堆星号，看着像乱码？**

这不是编码坏了，是「加粗被表达了两次」。很多人习惯先在别处写好 `**加粗**`、`### 标题`，
再整段粘进 Word —— Word 里这些字**同时又是加粗格式**。旧版转换时把 `**` 转义成 `\*\*`，
外面又自动加一层 `**`，叠在一起就成了 `\*\***检索条件…\*\***`。

现在两条路都通了：

- **重新转一次**：把 Word 再拖进 bat，出来就是干净的 `**加粗**` 和 `### 标题`
- **老文件不用重转**：在编辑器里打开时会自动清理，屏幕下方提示「已自动清理 N 处多余的星号」

判断依据很稳：只有「反斜杠 + 两个以上星号」这种人手打不出来的组合才会被清理，
正文里正经的 `**加粗**`、单个星号、`***粗斜体***` 一个字都不会动。

**Q：文章里的网址是一串灰字，点不动？**

Markdown 里「光写网址」不算链接，要写成 `<https://...>` 或 `[文字](https://...)` 才认。
现在 **bat 转 HTML 稿** 和 **编辑器「导入 HTML」** 都会自动把纯文本网址包成 `<网址>`，
转出来在预览和博客上都能直接点。

之前已经转好的老文章有两种补救办法：
- 把同一篇 HTML **重新「导入 HTML」一次**（注意会整篇覆盖，改过的字要先备份）
- 或者手动在网址前后各加一个**半角尖括号**：`<https://busuanzi.ibruce.info>`

**Q：粘一大段 Markdown 进去，浏览器提示「页面无响应」？**
这一版已经修好了。原因是旧版每敲一个字都要把整篇文章重新排一遍，
文章一长（几万字以上）就会卡住几秒；现在改成**切段、一屏一屏地画**，
长文章渲染时右上角会显示「正在渲染 xx%」，期间照样能打字、能滚动。
另外图片也改成**滚到哪儿才加载哪儿**，图片多的老文章不会再拖慢浏览器。

**Q：双击 bat 一闪就没了？**
说明脚本报错了。请在这个文件夹里按住 Shift 点右键 →「在此处打开 PowerShell 窗口」，
输入 `powershell -ExecutionPolicy Bypass -File .\word2md.ps1` 回车，看具体报什么错。

**Q：我把它拷到桌面 / U盘上了，会报「没找到博客目录」吗？**

不会了。从这一版起：**找不到博客目录就自动进便携模式**，把文章放进工具文件夹里的 `输出\`，
不再弹红字、不再让你指定路径。想直接写进博客，加 `-Root` 指明位置即可：

```powershell
powershell -ExecutionPolicy Bypass -File .\word2md.ps1 -Root "D:\我的博客" -Files "稿子.docx"
```

判断标准很简单：**哪个文件夹里有 `_config.yml`，它就是博客根目录**。
详见「八、当成随身小工具用」。

**Q：提示「只支持 .docx / .html / .htm」？**
老格式的 `.doc` 需要先转一次：用 Word 打开它 →「文件」→「另存为」→
文件类型选 **Word 文档 (\*.docx)** → 保存，再拿新文件来转。
另外，`.mht`、`.webarchive` 这类「单文件网页」不支持，用浏览器打开后
「另存为」成 `.html` 即可。

**Q：转出来的 HTML 里混进了导航、广告、评论？**
转换时会自动跳过导航、页脚、侧边栏、脚本和样式。如果某网站的页面结构特别，
个别残留会出现在正文里 —— 用编辑器打开，手动删掉那几行就行，很快。

**Q：网页文章很长，转出来缺了一大段？**
多半是「懒加载」造成的：真正的正文要在浏览器里滚动才会加载出来，
而你保存的 HTML 里只有空壳。解决办法是在浏览器里滚到底再保存网页，
或者直接在编辑器里粘贴页面上看到的内容。

**Q：转换后公式、批注、页眉页脚不见了？**
这些 Markdown 本来就不支持，属于正常。页眉页脚本来也不该出现在正文里。

**Q：表格第一行跑到表格上面去了？**
Word 里表格第一行如果是一个横跨整行的合并单元格（法律文书里常见的大标题），
脚本会把它当成「表格标题」挪到表格上方加粗显示。这是故意的，更好看。

**Q：编辑器预览里图片是一片空白？**
先看是不是网址不全（`//up.itc.cn/...` 或 `/up.itc.cn/...`），现在工具会自动补全。
补完还空白，会显示虚线框写着「图片加载不出来：网址」，点一下能在浏览器打开验证。
三种常见原因：图片已经被删除、对方网站禁止外链、你这边断网。
如果只是本地看不到、但浏览器能打开那个网址，那多半是对方只允许特定来源，
放到网站上通常就能正常显示。

**Q：图片位置错乱？**
文本框、艺术字里的图片抓不到，属于已知限制。遇到就在编辑器里手动删掉那一行，重新插图。

**Q：会改坏我的原文件吗？**
不会。全程只读取，原件一个字节都不动。

## 七、进阶：不用问答，一次转一批

在 `tools` 文件夹里按住 Shift 点右键 →「在此处打开 PowerShell 窗口」，然后：

```powershell
# 一次转一整个文件夹（Word 和网页都会转），全部用默认分类
powershell -ExecutionPolicy Bypass -File .\word2md.ps1 -Files "D:\稿子" -Yes

# 全部指定成同一套分类、标签、日期
powershell -ExecutionPolicy Bypass -File .\word2md.ps1 -Files "D:\稿子\*.html" `
    -Category "工作/文书模板" -Tags "文书模板,实务教程" -Date 2026-10-28 -Yes

# 只看转换效果，不真的生成文件（安全预览）
powershell -ExecutionPolicy Bypass -File .\word2md.ps1 -Files "稿子.docx" -DryRun
```

可用参数：

| 参数 | 意思 | 例子 |
| --- | --- | --- |
| `-Files` | 要转的文件，可多个，也可写文件夹 | `"D:\稿子"` |
| `-Title` | 指定标题（不给就自动认） | `-Title "民事起诉状要点"` |
| `-Category` | 分类 | `-Category "工作/诉讼实务"` |
| `-Tags` | 标签，逗号隔开 | `-Tags "合同纠纷,实务教程"` |
| `-Date` | 发布日期 | `-Date 2026-10-28` |
| `-Slug` | 文件名编号 | `-Slug post-051` |
| `-Yes` | 不提问，全用默认值 | `-Yes` |
| `-KeepTitle` | 正文里保留那行标题（默认删掉） | `-KeepTitle` |
| `-OutDir` | 指定输出目录（不用是博客） | `-OutDir "D:\我的输出"` |
| `-Root` | 指定博客根目录（一般不用写，bat 会自动传） | `-Root "D:\我的博客"` |
| `-DryRun` | 只预览不写文件 | `-DryRun` |
| `-MaxWidth` | 图片最大宽度，默认 1000 | `-MaxWidth 800` |
| `-JpegQuality` | JPEG 质量，默认 85 | `-JpegQuality 80` |

## 八、当成随身小工具用（拷到哪儿都能跑）

这套工具**不认电脑、不认路径、不认博客**，只看自己身边有没有博客。
所以你可以把它当成一个 U 盘小工具：拷到任何一台 Windows 电脑的任意文件夹里，双击就能用。

### 判断规则（你什么都不用选）

| 工具文件夹的位置 | 程序的行为 | 文件去哪 |
| --- | --- | --- |
| 在博客里（往上能找到 `_config.yml`） | 直接写进博客 | `_posts\` + `assets\img\` |
| 在其他任何地方 | **便携模式** | 同目录的 `输出\` 文件夹 |
| 加了 `-OutDir "D:\某处"` | 听你的 | 你指定的地方 |

便携模式启动时会打一行横幅告诉你，长这样：

```
  ── 便携模式 ──────────────────────────────────────────
  这个位置不是博客目录，所以不往 _posts 里写。
  生成的文章会放进：D:\工具\输出
  ──────────────────────────────────────────────────────
```

**不会报错、不会让你指定路径、不会把文件写到找不到的地方。**

### 便携包的文件夹长这样

```
稿件转Markdown工具\
├── 5-Word或HTML转Markdown.bat    ← 双击这个转换
├── 6-文章编辑器.html             ← 双击这个改稿（浏览器打开）
├── word2md.ps1                   ← 后台程序，别删
├── 使用说明.md                   ← 就是本文件
└── 输出\                         ← 转换结果自动出现在这里
    ├── 2026-10-28-post-001.md
    └── assets\img\post-001\xxx.png
```

### 打包带走（三步）

1. 选中这 4 个文件和 `输出` 文件夹（或者直接选整个文件夹）
2. 右键 →「发送到 → 压缩(zipped)文件夹」
3. 把生成的 `.zip` 拷到 U 盘 / 网盘 / 另一台电脑，解压就能用

> 想连"输出"里的东西一起清掉再打包：先把 `输出` 文件夹里的内容删掉，留个空文件夹就行。
> **空文件夹也能打包**，程序自己会建。

### 拿回博客发布

转换时不用管目录结构，回来再搬：

1. `输出\` 里的 `.md` → 拖进博客的 `_posts\`
2. `输出\assets\img\` 里的那个文件夹（比如 `post-001`）→ 拖进博客的 `assets\img\`
3. 图片路径在 md 里写的是 `/assets/img/post-001/xxx.png`，搬进去就对得上
4. 双击 `deploy.bat` 发布

> 网页（HTML）转出来的图片是**网络地址**，不需要搬，第二步可以跳过。

### 别的电脑上第一次运行，可能遇到的

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 蓝色窗口一闪就没 | 脚本报错 | 说明文档最后的「常见问题」有排查法 |
| 提示「Windows 已保护你的电脑」 | 从网上下的文件被标记 | 点「更多信息」→「仍要运行」 |
| 双击 `.ps1` 提示「禁止运行脚本」 | Windows 默认策略 | **别双击 ps1**，双击那个 `.bat` 就行，它已经带放行参数 |
| 中文显示成一串问号 | 对方电脑是英文系统 | 不影响转换结果，文件内容是正常的 |
| 提示没法创建输出文件夹 | 在只读位置（U盘写保护、光盘） | 把整个文件夹拷到桌面再用 |

### 一个提醒

`输出` 文件夹里的 `post-001` 编号是**按这个文件夹自己算的**，
搬回博客后可能和你博客里已有的 `post-051` 撞号 —— 这不影响文章，
图片路径和文件名是配套的，一起搬就没问题。想改名就两个一起改。
