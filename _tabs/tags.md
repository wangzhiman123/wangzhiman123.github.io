# ============================================================
# tags.md —— 顶部的"标签"页面
# ------------------------------------------------------------
# 【这个文件干什么用】
#   这是网站顶部导航栏里"标签"那一页，本身没有内容，
#   只负责告诉程序"请用 tags 版式渲染我"。
#   所有标签的汇总列表由那个版式自动生成。
#
# 【运行效果】
#   点顶部"标签"，会看到一大片标签（像云朵一样大小不一，越常用越大），
#   点击某个标签能看到所有带该标签的文章。
#
# 【下面几行夹在两个 --- 之间，叫 front matter，是这一页的设置项】
#   注意：front matter 必须写在文件最开头，前面不能有其他内容。
# ============================================================

# layout：用主题自带的"标签汇总页"版式，不要改成别的。
layout: tags

# icon：导航栏上这一项显示的图标。
# 【可DIY修改】换成别的 Font Awesome 图标名即可换图标。
icon: fas fa-tags

# order：在导航栏里的排序位置，数字越小越靠前。
# 【可DIY修改】可调整顺序，注意与其他页面错开数字。
order: 2
