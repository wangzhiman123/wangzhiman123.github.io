# ============================================================
# categories.md —— 顶部的"分类"页面
# ------------------------------------------------------------
# 【这个文件干什么用】
#   这是网站顶部导航栏里"分类"那一页。它自己几乎没有内容，
#   只是告诉程序"请用 categories 版式来渲染我"。
#   所有文章按分类汇总的列表，都由那个版式自动生成。
#
# 【运行效果】
#   点顶部"分类"，会看到按分类归拢好的文章目录树，
#   点某个分类能展开看到该分类下的全部文章。
#
# 【下面几行夹在两个 --- 之间，叫 front matter，是这一页的设置项】
#   注意：front matter 必须写在文件最开头，前面不能有其他内容，
#   否则程序会把它当成普通文字显示出来。
# ============================================================

# layout：指定这一页用哪个"模板排版"。
# categories 表示用主题自带的"分类汇总页"版式，不要改成别的。
layout: categories

# icon：这一页在顶部导航栏显示的图标。
# 图标名来自 Font Awesome 图标库，这里是一个"列表/流"的样子。
# 【可DIY修改】换成别的图标名（如 fas fa-folder），导航栏图标就变了。
icon: fas fa-stream

# order：在导航栏里的排序位置，数字越小越靠前。
# 【可DIY修改】改成别的数字可以调整导航栏顺序，
# 但要和 _tabs 里其他文件（tags=2、archives=3、about=4）的数字错开，避免打架。
order: 1
